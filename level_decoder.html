Level Record Decoder

Turns the binary get_level.hw file (the level record) into readable LevelXML. Everything runs in your browser: nothing is uploaded.

Levels belong to their authors. Use this to study, convert or back up levels for your own use; do not republish other people's levels without permission.

1. Files

or click to choose them. They are told apart automatically by their content.

2. LevelXML

Tutorial: getting the required files

  1. Open the level you want to get the level code from.
  2. Right-click anywhere on the page and choose Inspect.
  3. Go to the Network tab and reload the page if needed.
  4. Use the filter box in the Network tab to search for get_level.hw. Two files with that name will show up.
  5. Right-click each one and save/download it (for example with "Save response as…"). Download both.
  6. Drop both files into the box above. They have the same name, but the app tells them apart by their content.

Tip: save the files with the browser’s save option. Copying the response as text corrupts the binary record.
